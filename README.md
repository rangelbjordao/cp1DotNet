# Calculadora Básica

Projeto desenvolvido em C# utilizando Windows Forms, com objetivo de praticar programação orientada a objetos e criação de interfaces gráficas.

## Funcionalidades
- Operações básicas: soma, subtração, multiplicação e divisão  
- Potenciação e raiz quadrada  
- Suporte a números decimais  
- Tratamento de erros (ex.: divisão por zero)  

## Tecnologias Utilizadas
- C#  
- Windows Forms (Visual Studio 2022)
